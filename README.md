# 操作系统实验模拟系统

## 📖 项目简介

这是一个基于 JavaFX 开发的操作系统课程实验可视化模拟系统，通过图形化界面直观展示操作系统核心概念和算法的工作原理。系统包含四个完整的实验模块，涵盖了进程管理、同步机制和调度算法等核心内容。

### ✨ 主要特性

- 🎯 **可视化教学**：通过动画和实时数据展示抽象的操作系统概念
- 🔄 **交互式体验**：用户可以实时控制实验参数并观察结果
- 📊 **数据统计**：提供详细的性能指标和运行状态监控
- 🎨 **美观界面**：采用现代化UI设计，提升学习体验
- 🔧 **模块化架构**：清晰的代码结构便于扩展和维护

## 🧪 实验模块

### 实验一：进程并发模拟

**目标**：理解进程并发执行的基本概念和资源共享机制

**功能特点**：
- 模拟多个进程同时执行的场景
- 展示独立进程与共享资源进程的区别
- 实时显示网络带宽占用情况
- 模拟进程执行的随机性和间断性

**技术实现**：
- 使用多线程模拟并发执行
- 动态调整共享资源访问速度
- 可视化展示进程状态变化

### 实验二：生产者与消费者问题

**目标**：掌握进程同步机制和AND信号量的应用

**功能特点**：
- 实现经典的生产者-消费者模型
- 使用AND信号量解决同步问题
- 实时显示信号量状态变化
- 详细记录PV操作执行过程

**技术实现**：
- AndSemaphore类实现原子性信号量操作
- Buffer类管理缓冲区访问控制
- 多线程安全的数据交换机制

### 实验三：进程调度模拟

**目标**：理解不同进程调度算法的工作原理和性能差异

**支持算法**：
- FCFS（先来先服务）
- SJF（短作业优先）
- RR（时间片轮转）
- Priority（优先级调度）

**功能特点**：
- 可视化展示调度过程和甘特图
- 实时计算平均等待时间和周转时间
- 支持自定义进程参数
- 比较不同算法的性能表现

### 实验四：多级反馈队列调度

**目标**：深入理解复杂调度算法的实现机制

**功能特点**：
- 实现三级反馈队列调度算法
- 动态调整进程优先级
- 实时监控各队列状态
- 统计降级次数等关键指标

**技术实现**：
- 多级队列管理机制
- 进程动态升降级策略
- 累计时间片控制算法

## 🎮 使用说明

### 主菜单导航

1. 启动程序后进入主菜单界面
2. 选择对应的实验模块进入
3. 每个实验都有详细的操作说明
4. 可随时返回主菜单切换实验

### 通用操作流程

1. **参数设置**：根据实验要求配置相关参数
2. **启动实验**：点击开始按钮启动模拟过程
3. **观察现象**：实时查看动画效果和数据变化
4. **分析结果**：结合统计数据理解算法原理
5. **重置实验**：清空当前状态重新开始

### 实验一：进程并发

- 勾选需要运行的进程
- 观察不同颜色小球的运动轨迹
- 注意网络进程的相互影响
- 查看实时带宽占用情况

### 实验二：生产者消费者

- 分别控制生产者和消费者的启停
- 观察缓冲区状态变化
- 关注信号量值的实时更新
- 分析PV操作的执行顺序

### 实验三：进程调度

- 选择调度算法类型
- 添加具有不同属性的进程
- 观察调度过程和甘特图生成
- 比较各项性能指标

### 实验四：多级反馈队列

- 了解各级队列的时间片限制
- 观察进程在不同队列间的迁移
- 分析降级机制的工作原理
- 统计整体调度效率

## 🐛 常见问题

### Q1: 程序无法启动

**可能原因**：
- JDK版本不兼容
- JavaFX依赖缺失
- Maven配置错误

**解决方案**：
```bash
# 确认Java版本
java -version

# 重新构建项目
mvn clean install
```

### Q2: 界面显示异常

**可能原因**：
- CSS样式加载失败
- FXML文件路径错误
- 资源文件缺失

**解决方案**：
- 检查resources目录结构
- 验证FXML文件语法
- 确认CSS文件存在

### Q3: 多线程问题

**可能原因**：
- UI线程访问冲突
- 同步机制不当
- 资源竞争条件

**解决方案**：
- 使用Platform.runLater()更新UI
- 正确实现同步控制
- 避免死锁情况
